# Hybrid Crypto System (HCS)

## 🚀 Основные возможности

*   **Гибридная криптография:** Связка **AES** (для быстрого шифрования данных) и **RSA-OAEP** + **PSS/PKCS#1 v1.5** (для безопасного шифрования и подписи ключей).
*   **Защита паролем:** Доступ к шифрованию ключа защищен с помощью **хэширования с солью**. Ввод пароля может быть скрыт в консоли через `getpass`.
*   **Автоматическая докачка зависимостей:** Встроенный загрузчик через `subprocess` сам проверяет и устанавливает нужные библиотеки при первом запуске.
*   **Адаптивный интерфейс:** Не сложное управление. Деление на 5 разных меню.
*   **Удобство (UX):** Удобные настройки: возможность включить автоматическое копирование зашифрованного текста в буфер обмена, скрытие пароля на экране, включение пароля и включение шифрования им ключа.
## ⚙️ Как это устроено

1.  **Симметричный уровень:** Для самого текста генерируется случайный временный ключ **AES**.
2.  **Асимметричный уровень:** Этот AES-ключ запечатывается с помощью открытого ключа **RSA-OAEP**.
3.  **Безопасность паролей:** Пароли на вход и на ключ шифрования не хранятся в открытом виде — они защищены уникальной «солью» и криптографическим хэшем.
### Запуск из исходного кода
Клонируй репозиторий и запусти главный скрипт с помощью git-scm:

