# Hybrid Crypto System (HCS)

**HCS** — консольный криптографический мессенджер-шифровальщик на Python, созданный для безопасного обмена текстовыми сообщениями через любые публичные каналы связи.

---

## 🚀 Основные возможности

* **Гибридное шифрование:** Сочетает скорость симметричного шифра **AES** (`Fernet`) с криптографической стойкостью асимметричного **RSA-OAEP** (2048, 3072 или 4096 бит).
* **Цифровая подпись (RSA-PSS):** Каждое сообщение подписывается приватным ключом отправителя, что гарантирует подлинность автора и защиту от подмены данных при передаче.
* **Скрытый формат пакета:** Зашифрованный сеансовый ключ, сжатое через `zlib` сообщение и подпись склеиваются в единый бинарный поток без открытых разделителей и кодируются в Base64.
* **Усиленная защита ключей (`KeyManager`):**
  * Приватный ключ шифруется на диске с помощью современного memory-hard алгоритма **Argon2id** и шифра **AES-GCM**.
  * Расшифрованные ключи и мастер-пароль удерживаются в изменяемом буфере (`bytearray`) и физически затираются нулями в оперативной памяти при блокировке или выходе.
  * Атомарная запись файлов защищает ключи от повреждения при внезапном сбое питания.
* **Удобство и автономность:**
  * Поддержка скрытого ввода пароля (`getpass`), автокопирования в буфер обмена и режима разработчика (телеметрия размеров пакетов и криптографических блоков).
  * Автоматическая проверка обновлений на GitHub и автоустановка зависимостей при запуске `.py` версии.

---

## ⚙️ Как это устроено

1. **Генерация ключей:** Пользователь создаёт пару ключей RSA (публичный `my public key.json` и приватный `private key.json`).
2. **Обмен ключами:** Собеседники обмениваются публичными ключами (через встроенный импорт/экспорт или при личной встрече).
3. **Отправка сообщения:**
   * Текст сжимается алгоритмом `zlib` и шифруется одноразовым ключом **AES**.
   * Ключ AES запечатывается публичным ключом получателя через **RSA-OAEP**.
   * Формируется цифровая подпись **RSA-PSS** на основе приватного ключа отправителя.
4. **Получение сообщения:** Программа по размерам модулей `n` автоматически разделяет бинарный пакет на заголовок, тело и подпись, проверяет целостность подписи, расшифровывает сеансовый ключ и восстанавливает исходный текст.

## 📦 Установка и запуск

### Вариант 1: Готовый исполняемый файл (Windows)
Скачайте актуальный **`HCS.exe`** со страницы [Releases](https://github.com) и запустите его. Установка Python не требуется.

### Вариант 2: Запуск из исходного кода
1. Склонируйте репозиторий или скачайте файл `HCS.py`:
   ```bash
   git clone https://github.com/v0mp1r/HCS
   cd HCS
   ```
2. Запустите скрипт (необходимые библиотеки `cryptography`, `bcrypt`, `pyperclip` установятся автоматически при первом старте):
   ```bash
   python HCS.exe
   ```
